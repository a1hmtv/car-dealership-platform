# Как установить и проверить

## Какой архив выбрать
- `car-dealership-complete.zip` — самостоятельный проект, без исходной папки `.git`, IDE-кэшей и сборочных артефактов. Распакуйте в новую папку и откройте корневой Gradle-проект в IntelliJ IDEA.
- `car-dealership-final-fixes.zip` — накопительный патч к исходному `lliizzaaa_template.zip`. Включает прошлые исправления, обновлённую конфигурацию, тесты и README. Скопируйте файлы с сохранением структуры целиком, включая скрытые `.github`, `.gitignore`, `.dockerignore` и `docker/.env.example`. Не заменяйте целые каталоги, чтобы не удалить другие исходники. Сначала сделайте резервную копию или коммит своих локальных правок.

Старый пустой `docker/Dockerfile` и отслеживаемые `.idea/*` в полном архиве исключены. В существующем репозитории можно удалить пустой `docker/Dockerfile`, а IDE-файлы убрать из индекса через `git rm -r --cached --ignore-unmatch .idea` (локально они останутся). Не удаляйте свой `.git`.

## Сборка и запуск
1. Установите Java 21 для локальной сборки и запустите Docker Desktop.
2. Из корня проекта выполните:

```bash
bash ./gradlew clean build
cp docker/.env.example docker/.env
docker compose --env-file docker/.env -f docker/docker-compose.yml config --quiet
docker compose --env-file docker/.env -f docker/docker-compose.yml up --build -d
```

Если `.env` уже существует, не перезаписывайте его: сравните с примером и добавьте недостающие переменные. Gradle Wrapper требует сеть при первой сборке. Dockerfile строит jar из исходников, отдельный локальный `bootJar` не нужен. Swagger: http://localhost:8082/swagger-ui/index.html и http://localhost:8083/swagger-ui/index.html.

## Важно про старую БД
Пример окружения содержит новые локальные пароли: `postgres-local`, `dealer-local`, `admin-local`. Для уже инициализированного тома PostgreSQL изменение POSTGRES_PASSWORD не меняет пароль существующего пользователя. Используйте текущие учётные данные в docker/.env или обновите их в БД осознанно. Не удаляйте тома без резервной копии; если хотите чистый демонстрационный запуск, используйте другое имя Compose-проекта (`-p dealer-portfolio`) и убедитесь, что прежние контейнеры не занимают порты. В старой БД может потребоваться сверить активные резервы и устранить дубли source_order_id до миграции. Новая миграция добавляет 10 единиц демонстрационной детали, только если записи остатков для неё ещё нет.

## Проверка
- Компиляция изменённых production Java-классов: javac 21 с классами и библиотеками из исходных Boot JAR — успешно.
- Smoke-проверка PartStock: резервирование, освобождение, списание, отклонение недопустимых операций — успешно.
- Синтаксический разбор YAML и XML SVG — успешно.
- Полная сборка Gradle: попытка завершилась UnknownHostException для services.gradle.org, до компиляции/тестов. Docker CLI в среде проверки отсутствовал. Новые JUnit-тесты и интеграционные тесты не запускались. Compose, миграции и работу RabbitMQ нужно проверить на Mac / CI.

## Граница изменений
Новый Outbox ожидает подтверждение и отсутствие возврата от RabbitMQ; повторная доставка возможна. Устранение дублей реализовано для основных сценариев; не гарантирует exactly-once. Возврат платежей, полноценная DLQ, конкурентные обновления через другие CRUD-интерфейсы и распределённая блокировка нескольких экземпляров Outbox остаются вне этой доработки. Keycloak start-dev и аккаунты из demo realm предназначены только для локального запуска. Перед открытой публикацией проверьте правила университета и не добавляйте личные токены, пароли или данные.
